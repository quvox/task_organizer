# テストシナリオ

### テスト1

workerのライフサイクルをテストする。
* workerがタスク指示を受け取る
* aiコルーチンを起動して、タスクを実行する
* AIエージェントによるタスクが完了したあと、タスク完了通知を出して、aiコルーチンを終了する



### テスト2

タスク指示とリストを作り、masterと1つのworkerの状況を作り、正常動作を確認する。タスク指示とリストは以下の通り。

```text
指定された数値について、以下の計算を行ってください：

1. その数値の2乗を計算
2. その数値が素数かどうかを判定
3. その数値の約数をすべて列挙

計算結果はcalculations/ディレクトリに、「calc_<数値>.txt」というファイル名で保存してください。
```

```text
17
25
31
```

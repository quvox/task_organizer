# 要件

ツール名は、taskorganizerとする。

このツールには、タスク生成機能、タスク管理機能、タスクワーカー機能という3つの機能を持ち、コマンド引数でどの機能を利用するかを選ぶ。

このツールは、src/の下にgoで実装する。

ビルドやインストールのためのMakefileを用意する。

macOS、Linux、windowsに対応した実行バイナリをビルドできるようにする。

loggingライブラリを使って、システムログやデバッグログを出力できるようにし、debug/info/warn/fatalのログレベルを選択できるようにする。

タスクの進行状況を保存し、途中から再開できるようにする。

AIエージェントにclaudeを用いる場合、ワーカーごとにセッションを引き継ぎ、初回起動時のオーバーヘッドの発生を防ぐ。
